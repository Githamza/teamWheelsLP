# HTML validation

`npm run validate:html` runs [html-validate](https://html-validate.org) over the
generated `public/` tree. Run `hugo --gc --minify` first.

## Why some rules are relaxed

The deployed HTML is **minified** (`[minify] minifyOutput = true`), so a handful
of html-validate rules fire on artefacts of the minifier rather than on anything
wrong with the templates:

| Rule | Why it is off / relaxed |
|---|---|
| `attr-quotes`, `doctype-style`, `void-style`, `attribute-boolean-style`, `no-trailing-whitespace` | Purely stylistic; the minifier strips quotes, lowercases the doctype and collapses whitespace by design. |
| `no-raw-characters` → `relaxed` | The minifier rewrites `&amp;` back to a bare `&` wherever HTML5 permits it (an ampersand that is not followed by an entity-like sequence). `relaxed: true` matches the spec — and the W3C validator — by only flagging genuinely ambiguous ampersands. |
| `hidden-focusable` | The Bootstrap video modal carries `aria-hidden="true"` while it is `display: none`, so its close button is not in fact focusable. Bootstrap 5's own markup does the same. |
| `prefer-native-element` | The navbar dropdown toggles use Bootstrap 5's documented `<a href="#" role="button">` markup. Swapping them for `<button>` would mean forking the theme's navigation CSS. |
| `valid-id` | Goldmark derives heading anchors from the heading text, so the numbered sections of the legal pages get ids like `1-who-we-are`. HTML5 allows an id to start with a digit; renaming them would break every existing deep link. |
| `require-sri` | Third-party tags (GA, Clarity, Crisp, Bing UET, LinkedIn) are versionless endpoints that cannot be pinned with an integrity hash. |
| `no-inline-style` | Inline `style` attributes come from the theme's SVG wave decorations. |
| `wcag/h30`, `h32`, `h37`, `h63`, `h67`, `h71` | Duplicated by the more precise `element-required-attributes` / `unique-landmark` / `text-content` rules already enabled. |
| `long-title` | `<title>` length is enforced editorially (≤ 60 characters, see the `seoTitle` front-matter field), not by this linter's 70-character default. |

Everything else runs at `html-validate:recommended`.
